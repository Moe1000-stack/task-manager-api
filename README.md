# Task Manager API

A Python REST API for managing tasks with full CRUD operations, input validation, error handling, and JSON-based storage.

This project demonstrates backend development fundamentals including API design, routing, data validation, and persistent file storage.

---

## Features
- Create new tasks
- View all tasks
- View a single task by ID
- Update task details
- Mark tasks as completed
- Delete tasks
- Validate user input
- Return proper JSON responses and HTTP status codes
- Store task data in a JSON file

---

## Tech Stack
- Python
- Flask
- JSON file storage
- REST API design
